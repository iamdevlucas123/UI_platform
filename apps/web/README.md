# apps/web (placeholder)

Este diretório é reservado para o frontend Next.js do projeto.

Conforme `docs/MVP1.md`, o MVP1 cobre apenas a fundação do monorepo e a API
backend — **nenhuma dependência de frontend é instalada nesta etapa**. Por
isso `apps/web` não possui `package.json` e ainda não faz parte dos
workspaces do pnpm.

Next.js 15 (App Router), TypeScript, Tailwind CSS, shadcn/ui e a integração
com Clerk serão adicionados aqui somente no **MVP2**.
